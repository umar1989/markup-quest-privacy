# Privacy Policy — Markup Quest

_Effective date: 23 November 2026_  ·  Contact: um.tn.in@gmail.com

Markup Quest ("the app") is an offline learning app for HTML and CSS. **It does not collect, transmit, sell or share
any personal data.**

## Data stored on your device
- Learning progress, XP, streak, badges and settings
- Code snippets you choose to save in the Code Lab

This data stays in the app's private storage on your device. It is never uploaded. It is excluded from Android cloud backup.
You can erase it at any time with **Me → Reset all progress**, or by uninstalling the app.

## What the app does not do
- No accounts, sign-in or registration
- No advertising and no advertising identifiers
- No analytics, tracking, profiling or crash-reporting services
- No access to contacts, location, camera, microphone, photos or files
- No third-party SDKs that collect data
- No network access: code you run in the Code Lab executes in an isolated frame and cannot send data anywhere

## Exporting code
If you tap **Export**, the app creates an `.html` file in its private cache and opens Android's share sheet. Where the
file goes next is your decision; the app has no access to the destination.

## Children
The app has no social features, purchases, ads or external links and is suitable for learners of all ages. It does not
knowingly collect any information from anyone, including children.

## Changes
If this policy changes, the new version will ship with an app update and the effective date above will change.
